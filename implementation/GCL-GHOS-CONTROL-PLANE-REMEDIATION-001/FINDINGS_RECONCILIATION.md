## Design gate

The evidence justifies remediation, but not a new normative GH-OS version by default. The minimum design should first enforce already-intended authority precedence, current-version propagation, exact-subject evidence, durable bounded transaction state, deterministic transition derivation, and executor/work-package compatibility. A normative successor is justified only if these controls cannot be introduced as subordinate implementation and conformance machinery under existing authority.
